# MEDIASERVI

Web principal de **mediaservi.com**.

Página de una sola pantalla, sin scroll: cinco diapositivas (Inicio, Conecta, Favoritos, Proyectos, Cómo llegar) que se recorren con flechas, rueda, teclado o deslizando el dedo, con cortinilla de paneles LED y fondo de humo y haces de luz en WebGL.

**Versión actual: beta-1**

- beta-1: primera versión con el contenido de la web actual (vídeo, redes, experiencias favoritas, proyectos y cómo llegar).
