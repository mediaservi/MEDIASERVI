# Tipos de letra alojados en este repositorio

Todos se distribuyen bajo la **SIL Open Font License 1.1** (https://openfontlicense.org), que permite usarlos, copiarlos y redistribuirlos. Los archivos son los mismos que publica Google Fonts, tomados del proyecto Fontsource, en su subconjunto latino.

| Tipo | Archivos | Autores |
|---|---|---|
| Doto | `doto-latin-600/800/900-normal.woff2` | The Doto Project Authors |
| Inter | `inter-latin-400/600/700/800/900-normal.woff2` | The Inter Project Authors |
| Share Tech Mono | `share-tech-mono-latin-400-normal.woff2` | Carrois Type Design |
